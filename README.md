# Fundamentos de Lógica y Algoritmos 🧠💻

Este repositorio es una colección de proyectos, ejercicios y resoluciones algorítmicas desarrollados para consolidar las bases de la programación estructurada y el pensamiento computacional. 

Aunque mi enfoque actual se dirige hacia la Ciencia de Datos y el desarrollo de software avanzado, considero fundamental mantener y demostrar un dominio sólido de las estructuras de datos, el control de flujo y la lógica base de la programación.

## 📂 Contenido del Repositorio

Actualmente, este repositorio contiene los siguientes proyectos:

| Proyecto | Lenguaje | Descripción | Habilidades Destacadas |
| :--- | :---: | :--- | :--- |
| [**Juego de Adivinanza**](./Juego_Adivinanza) | C++ | Juego interactivo de consola con dificultad dinámica. | Validaciones, bucles `while`, arreglos, algoritmos de ordenamiento (`std::sort`), manejo de estado. |

*(Nota: Este repositorio se irá actualizando a medida que incorpore nuevas implementaciones algorítmicas, estructuras de datos clásicas o resoluciones de problemas lógicos).*

## 🛠️ Tecnologías y Conceptos

Los proyectos aquí alojados se centran en los siguientes conceptos clave:

*   **Estructuras de Control:** Condicionales complejos y bucles de iteración.
*   **Estructuras de Datos:** Manejo de arreglos (arrays), vectores y listas.
*   **Algoritmia:** Búsquedas lineales, algoritmos de ordenamiento y generación de valores pseudoaleatorios.
*   **Validación y Robustez:** Prevención de errores de entrada y manejo de excepciones lógicas.
*   **Buenas Prácticas:** Código limpio, tipado estricto (en C++) y estructuración procedimental.

## 🎯 Propósito

El objetivo de mantener estos proyectos no es mostrar aplicaciones complejas orientadas a producción, sino evidenciar **cómo pienso y resuelvo problemas** desde la base. Una buena lógica de programación es el cimiento necesario para escribir algoritmos eficientes en Machine Learning, consultas SQL complejas o aplicaciones web escalables.
